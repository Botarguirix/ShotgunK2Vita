# Herramienta de rendimiento / Performance tool

## Español

`tools/perf_tool.py` analiza diagnósticos locales y configura perfiles; consulta `python tools/perf_tool.py --help`. En Windows también están `PerformanceTool.cmd` y `PerformanceTool.ps1`. Respalda tu configuración antes de aplicar cambios. Los logs y datos analizados permanecen privados.

La release incluye un `performance.cfg` opcional. Instalarlo sustituye tus ajustes: cópialo sólo después de respaldar `ux0:data/shotgunk2vita/performance.cfg`. El límite de FPS y el reloj solicitado no garantizan rendimiento real. Comparar escenas equivalentes, configuración, duración y hardware; las pruebas PC no representan FPS de Vita.

## English

`tools/perf_tool.py` analyzes local diagnostics and configures profiles; see `python tools/perf_tool.py --help`. Windows launchers `PerformanceTool.cmd` and `PerformanceTool.ps1` are also available. Back up settings before applying changes. Logs and analyzed data remain private.

The release includes an optional `performance.cfg`. Installing it replaces your settings: first back up `ux0:data/shotgunk2vita/performance.cfg`. An FPS limit or requested clock does not guarantee actual performance. Compare equivalent scenes, settings, duration and hardware; PC tests do not represent Vita FPS.
