# Iteración 00.36 — LuaJIT Runtime Benchmark

Rama: xperiment/luajit-psvita.

Esta entrega es una puerta experimental de compatibilidad LuaJIT. Criterio:
Perfil comparable de CPU, draw, memoria y FPS. La macro experimental identifica la rama; el runtime permanece Lua 5.1
hasta que la integración real pase las pruebas de ABI, scripts y memoria.

No se declara mejora de FPS sin medición equivalente en Vita.
